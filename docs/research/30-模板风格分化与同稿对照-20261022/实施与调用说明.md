# 主题分化与同稿对照

本轮已接通两种可复用主题：明亮研究、深色展示。共用既有字号、网格和原生构图配方，区分角色色与选材方向；这是同一版式家族的主题扩展，不冒充两套全新商业模板。

两份四页样件包含封面、数据主导页、图片＋原生图表、行动结尾。文字、事实、来源和图片字节一致。图表为实际文件宽度1672、2560、1672px，不是审美或业务评分。两份均经本机 PowerPoint 导出并查看。

## 使用

在 ppt-workflow 目录执行：

```powershell
./.venv/Scripts/python.exe -m ppt_workflow theme-catalog
./.venv/Scripts/python.exe -m ppt_workflow theme-prepare --theme research-light --out runs/新任务/theme
```

深色用 `--theme showcase-dark`。template-catalog 同样列出 theme_families 和八张真实预览。两条新命令均归 ppt-template。

把 theme/design-system.json 交各原生图形预制与 brief-compose，把 theme/asset-style.json 交 asset-plan 和 materials-plan。素材仍先筛选、实际查看与封存；主题改变后重新制作原生片段，避免旧颜色混入。

详细调用与约束见[主题选择与同稿对照](../ppt-workflow/docs/主题选择与同稿对照.md)。可复现输入分别在 runs/theme-light-20261022-001 与 runs/theme-dark-20261022-001，准备示例为本目录 prepare_theme_example.py。
