# 模板风格分化与同稿对照

目标：将已有角色色扩展为制作链真正可用的两种主题，避免新任务一律暖白酒红。复用已有 academic/technical 色板，不复制上游源码。

1. 模板 Skill：根据使用环境比较明亮研究和深色展示。输出 design-system 和 asset-style 两个独立文件。
2. 素材准备：同一份逐页文案、事实、来源和同一张插画进入两份任务；图表、原生封面和结尾分别继承主题预制。检查素材预览。
3. 制作 Skill：通过 material-pack → brief-compose 组成四页样件，不另写批量排版引擎。
4. 实际效果检查：PowerPoint 导出两份实际页面，查看文字、图表轴、来源和图片裁切；必要时返修。记录数据和图片身份一致。
5. 审核交付：整套接触表与两份可编辑 PPT 提交用户选方向。未获得审美选择前不记录模板批准。
6. 固化：主题命令归 ppt-template；制作按既有主题交接，不在中途另选颜色。更新两项 Skill、调用说明与真实预览索引。

本轮验证控制在新主题绑定、命令归属、既有原生制作路径和实际八页导图；不扩展无关功能。
