# 在 WPS 中找到适合的模板

适用于用户要求去 WPS 找模板，或已有需求/大纲、没有强制品牌模板、且 WPS 可用的模板阶段。执行检索与打样，不把任务退回用户手工挑选下载；已有明确偏好和授权直接沿用。

## 按内容找模板

从需求和大纲提取受众、展示/阅读场景、时长、页数、比例、品牌色、图表/流程/时间线等版式需求，以及必须可编辑的对象。优先寻找能容纳实际内容结构的模板，再看封面装饰。缺少可选偏好时使用已知场景推进，不重新访谈已回答的问题。

将主题词与场景、风格或结构组合搜索，例如“科研汇报 简洁 图表”“项目汇报 商务 流程”“课程答辩 科技 简约”。这些只是例子，按任务换词；不要因旧样稿是绿色工作总结，就固定复用同一款模板。

## 打开与搜索

加载宿主当前提供的 Windows computer-use Skill，再发现 WPS 的实际窗口或安装入口。软件版本和路径可能变化，不硬编码旧机器路径、窗口坐标或元素编号。进入“新建→演示”或界面实际显示的演示模板入口，用当前搜索框和分类筛选。

已登录时直接使用当前会话，不要求重新登录或退出后台进程。需要登录、购买或权限处理时，按当时工具规则处理，不代填认证信息或自动追加付费。连接或界面不可用时记录实际失败，不声称已浏览模板库。

当前项目 MCP 的 wps-health 可查询桌面应用；它不搜索在线商城。会员库检索和“立即使用”在 WPS 界面执行，本地文件盘点与适配才调用 MCP。不要猜商城 API、抓取账号凭据或把 WPS 365 企业 MCP 当成个人模板库。

## 比较候选

通常比较 2–3 个有实质差异的候选；用户已指定款式或已有明显合适者时可直接打样。根据以下项目说明取舍：

| 项目 | 检查重点 |
|---|---|
| 场景匹配 | 受众、正式程度、展示距离与内容密度是否适合 |
| 版式覆盖 | 预览内容页，确认有大纲需要的图表、对比、流程等，不能只看封面 |
| 整套一致性 | 字体层级、色彩、留白、页眉页码和装饰语言是否统一 |
| 可编辑性 | 文字、图表、表格、图形是否独立，还是整页截图；装饰位图可保留 |
| 适配成本 | 实际页面比例、缺失字体、对象复杂度及替换长文本后的空间 |
| 使用范围 | 详情页标注的个人/商用等实际许可、水印和额外费用 |

选型理由围绕用户内容；说明最佳候选及实际缺项。候选摘要可独立保存在工作目录，不凭空增加 CLI 交接字段。会员身份不是商用许可，模板详情的比例、页数也需在下载后核实。

## 下载与原生检查

对选定候选点击实际界面的“立即使用”等入口，创建独立文稿，另存为绑定项目 `templates/imported/` 下的新 PPTX/POTX，WPS DPS 先另存 PPTX。使用新文件名，不覆盖既有业务稿或源模板。

为下载文件保存相邻来源记录，例如 `.source.json`：模板名称、提供方、可核实的详情链接（若有）、实际许可、获取日期、本次用途与原文件哈希。仅记录看到的信息，不猜作者、链接或授权，不保存账号标识或密钥。用户下载素材不进入通用安装包。

从相邻 runtime.json 解析项目根，在其目录调用：

```powershell
.\.mcp-venv\Scripts\python.exe scripts/office_mcp_client.py inspect-template runs/新的检查目录 templates/imported/候选模板.pptx
```

读取 template-resources.json，核对实际母版、布局、主题字体/颜色、占位符、形状 ID 和原生图表。预览好看或保存成功，不等于已确认可编辑。如果关键内容是一整页位图，按用户的原生编辑要求改选模板或明确重建成本。

## 三页打样与审核

选封面、数据/图表页、流程或复杂内容页作为代表，不机械照搬旧模板页号。结合已批准大纲替换示例文字；验证样稿中的图表仍用示意值时应标注，不能冒充业务数据。保留模板整体设计，登记对象映射。

本项目已验证的 wps-template 接受项目内请求 JSON：

```json
{
  "template_path": "C:/实际项目/ppt-workflow/templates/imported/候选模板.pptx",
  "pages": [1, 4, 9],
  "edits": [
    {"slide": 1, "shape_id": 16, "expected": "模板中的原文", "text": "按大纲替换的新文案"}
  ]
}
```

示例路径、页号、ID和原文须换成实际检查值。pages 为升序且不重复的源页号；edits 的 expected 来自原文，校验不符时停止。然后执行：

```powershell
.\.mcp-venv\Scripts\python.exe scripts/office_mcp_client.py wps-template runs/新的打样目录 runs/请求目录/request.json
```

该工具先制作物理文件快照，优先连接活动 WPS，只改自己的副本，保存并导出 PNG，再由独立进程只读重开核对。不 Quit 共享应用；不因占用或忙响应结束全部后台进程。失败时按报告定位，不忽略隔离锁或把未完成写为成功。当前支持选页和按对象修改文字、保留已有原生内容，不支持任意图表数据重写。

查看完整三页图像及接触表，检查替换后的换行、字体、裁切和跨页一致性；有图表时核对缓存与嵌入工作簿。将真实模板、设计规范、预览路径及适配边界整理为 template-selection.json，展示给用户审核。用户确认后才交 ppt-compose 批量适配；搜索、下载或技术验证本身不构成人工批准。
