# 版式与素材选择

先读绑定项目 `docs/页内排版与素材调用工作流.md`。这里的布局指常规Office/WPS幻灯片内文字、图表、图片的组织，不是改用竖版画布。依据任务画布做内容区域草图，确定阅读顺序、分组、对齐、图文比例与留白；不局限于两种步骤布局。

每次任务按页列素材需求，实际执行asset-search并保存results.json，查看原图后记录选择或不用的理由；有缺口再检索外部来源、生成或制作原生元素。按该文档保存page-visual-plan.md，向制作阶段交接布局与选材结果。现有5项位图只是库的起点，图标与可编辑模块按真实能力另行盘点。无需求的页面说明理由，不强行配图。

先确定每页的阅读顺序和主要视觉证据，再画两种小构图。选择网格、字号层次、图文比例与素材角色；真实代表页比仅写风格形容词更能说明设计。

在绑定项目运行asset-search，可用query、use、style、min-width筛选人工整理的素材。cover/scene/chapter/spot/process是素材用途标签，不等于模板已兼容。搜索结果是候选，不是美观评分。目录只含现有项目生成图，真实项目照片须另核对。

选图时读negative_space、recommended_focus、preferred_fit与limitations。背景看留白区，透明主体看边缘和完整性，人物图看视线与动作。将许可声明和来源带入制作请求，不把模拟图中的报表作为真实图表。

photo_process适合横向四步总览；photo_process_side提供纵向步骤和大侧图，文字容量更紧。根据图片原构图和阅读需求选用，不能认定后者总是更好。复杂文字先改布局，保持实际字号和内容覆盖。

完整方法、来源及命令见绑定项目docs/版式与素材设计方法.md。模板人审后才批量适配，保留原品牌和事实。
