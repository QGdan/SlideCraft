# 原生图表视觉表达优化

本轮优先解决原生图表“数据正确但主次与结论不清楚”的问题；保持已有图型范围和旧默认行为，不新增装饰图库或用截图代替图表。

1. 实现三种窄范围配方：单系列重点比较、双系列柱图比较、月度趋势。统一角色色、可读字号和图例位置，保留零基线和数据。
2. 新增chart-style-catalog与chart-prepare：后者接受已有来源/事实表和事实模板结论，输出原生图表＋原生结论文字片段与准备记录。结论不由图表命令臆测；计算结论仍须通过既有公式核对。
3. 用清楚标记的示意数据构建3页验证稿，检查缓存/工作簿/事实绑定，实际PowerPoint与WPS导图后修订。对照不宣称示意数据是研究结论。
4. 保存真实配方预览，补齐Skill与使用说明；运行新增与全量检查、同步Skill、汇总本轮证据。原业务PPT、历史批准及旧默认图表样式不改。

现场验证补充：发现本机WPS转存3个图表后丢失嵌入工作簿，虽然缓存仍能导图。新增转存保护门禁，拒绝将此副本当作成功交付；保留原始原生PPT，不回填过时数据或清除检查错误。检查器遇到WPS特有折线类型字段返回unknown并继续核对，而非崩溃或伪造通过。
