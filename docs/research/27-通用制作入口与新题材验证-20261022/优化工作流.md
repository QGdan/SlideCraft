# 通用制作入口与新题材验证

2026-10-22。三批源码迁移之后，继续解决新任务仍需临时拼页脚本的问题。本轮只做可复用制作入口与不同题材验证，不另建第七阶段或更换事实/审批规则。

1. 盘点现有交接，备份受影响文件；保留24–26号结果和原客户PPT。
2. 实现brief-compose，读取原大纲、已封存素材包、设计系统及逐页布局选择；保留页ID、主张、全部正文、来源和事实。图片正文沿用实测容量，原生关系和图表直接使用任务包片段。
3. 输出deck-spec、正文/素材对象映射及composition交接件。版式不在设计系统、缺必需素材、文字过量或引用不匹配时给出明确原因；不自动删文或改批准页数。
4. 用校园公共服务题材，实际检索并选用已有相关场景素材，制作图文、同维度比较、原生图表三类页。准备脚本只写内容和素材请求，拼页由通用入口完成。
5. PowerPoint导图查看整套，必要时修版式。只运行本轮相关检查，再同步模板/制作/总控Skill，整理可直接调用的例子。

审核D看新题材能否沿用同一入口，图文是否相关、文字是否完整、图表与跨页风格是否一致。自动检查不代替用户审美结论。
