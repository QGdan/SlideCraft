## 这次新增了什么

1. **更广的地图**：30 个项目/插件，覆盖原生库、标记语言、HTML/SVG、模板复用、Agent、评估六类。
2. **插件四形态**：MCP Server、Agent Skill、Dify/n8n 节点、Office 加载项/COM/WPS，并给出“四原语”设计建议。
3. **六种工作流**：Markdown 极速线、模板注入线、设计系统线、Agent 全自动线、平台/API 线、存量改造线，各自带质量门与适用边界。
4. **可编辑性 E0–E4**：把“支持 PPTX”拆成可判定的五级，并给出三个可计算指标。
5. **接入映射**：外部能力如何进入现有 `intake → outline → template → compose → polish → review`，以及明确不建议接入的项目。

## 三条最重要的结论

- **质量是乘法**：内容 × 叙事 × 视觉 × 工程 × 运维；任一层为 0，整体为 0。lint 0 error 只覆盖工程层的一部分。
- **模板是最高 ROI**：企业/学院场景优先模板注入；自由设计只在“无模板/发布级视觉”时值得投入。
- **零件化，不平台化**：保持 PptxGenJS 主引擎与六阶段工作流；把 PPT Master 的 SVG 编译、PPTAgent 的双评审、Presenton 的模板/API、Slidev 的 DOM 测量作为能力供应商。
