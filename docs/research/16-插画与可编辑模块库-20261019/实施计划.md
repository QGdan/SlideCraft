# 插画与原生模块接入

1. 从Open Peeps官方页面选取少量CC0人物插画，保存SVG、许可/页面快照、哈希与中文标签；实际看图后命名，不将人物组件冒称真实现场照片或完整场景。
2. 扩展现有asset-search/asset-prepare，新增illustration类型，保留默认5项图片检索与原图标接口。图片、图标、插画分类检索，素材准备记录页/对象/来源，运行时离线。
3. 建立原生可编辑模块目录：复用已有流程、对比、行动组件，新增里程碑时间线。提供module-search和module-prepare，后者输出原生对象片段，不用模块截图替代可编辑元素。
4. 用正常16:9的4张技术页检验图文分区与组件，通过实际PowerPoint/WPS导图、源对象核对和逐页查看发现问题并修订。按实际结果生成预览，再入目录。
5. 完成针对性与全量检查、文档/Skill同步及证据整理。技术样页不批准业务大纲/模板，不改客户原PPT。
