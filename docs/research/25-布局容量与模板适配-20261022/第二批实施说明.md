## 本批变化

从23号调研中迁移“用真实内容选布局、预留来源空间、测量文字再分配区域”的方法，自主实现，没有复制上游运行文件。没有新增笼统设计Skill，仍由大纲、模板、制作和审核各司其职。

- 新增layout-plan（ppt-template），按实际正文、证据类型比较单栏/双栏、两种图文比例和完整图表区，共五种配方，返回理由、替代方案与页数。
- 新增page-prepare（ppt-compose），产出原生文字片段和图片/图表区域，接入已有asset-place、chart-prepare与editorial-build。并不接管在线模板商城。
- 中文、数字、英文词组按本机微软雅黑实际字宽换行，处理指定中英文标点禁则。长正文保留完整原文及源位置，跨页加续段标题；锁定页数放不下时不生成制作片段。
- template-catalog新增真实内容模板索引，保存三类代表页、色板、字体、容量与使用范围。保留旧蓝图出口。
- 四个Skill入口已同步安装版本，runtime配置未改动；有修改前备份及安装版本备份。

## 实际效果

[三页代表PPT](审核B/布局与模板适配-代表页.pptx) · [三页预览](审核B/三页预览.png)

1. **长正文**：同一份实际文字，单栏需要两页、双栏一页；选择双栏且保留正文。该页是阅读材料的容量代表，现场演示仍需作者明确压缩或拆分叙事。
2. **图文**：照片完整比例入页，依据实际画面说明屋顶光伏阵列，保留作者与许可。图片由任务素材文件夹提供，没有临时在线替换。
3. **数据**：分配完整图表区域，继续使用既有原生图表与事实模板；数据为明确标注的合成示意数据，不作业务结论。文字和图表可编辑，照片为可替换位图。

三页已在PowerPoint真实导出并查看；24个原生文字框的只读文字边界检查未发现溢出，原生对象检查通过。受影响的布局、关系图、合同、图表和阶段路由共76项检查通过，未运行全库测试。全文OOXML模式校验、WPS保存与编辑往返不在本批验证范围内。具体记录见必要检查记录.json。

第一次构建发现新配方名尚未加入页面合同，已补齐；第二次导图发现照片文件名容易导致主体描述不准，已按实际画面改正文，并去除重复页脚。最终样例来自runs/layout-capacity-20261022-003，旧迭代没有作为交付件。原客户PPT哈希保持不变。

## 如何调用

在ppt-workflow目录，用项目虚拟环境运行：

```powershell
python -m ppt_workflow layout-plan --input examples/layout-body.json --out runs/新任务/布局候选
python -m ppt_workflow page-prepare --input examples/layout-body.json --out runs/新任务/正文片段
python -m ppt_workflow template-catalog
```

图片和数据分别有examples/layout-photo.json、examples/layout-data.json。每次输出用新目录。详细接入与边界见[内容驱动布局与中文容量](../ppt-workflow/docs/内容驱动布局与中文容量.md)。

目前限定常规宽屏与微软雅黑。原生关系继续用第一批relationship-prepare；封面、时间线、复杂表格仍走既有专用路线。新增模板索引为候选系统，通过page-prepare编译，不冒充旧blueprint格式或任意WPS模板兼容。
