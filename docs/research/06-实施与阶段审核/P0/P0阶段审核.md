## 实际遇到的问题及处理

1. 原 Python 环境缺 defusedxml/jsonschema，改为项目内 venv 固定安装，不修改全局包。
2. 受限执行器阻止 ensurepip 访问其新建临时目录；项目内临时目录仍受限，随后通过正常权限流程完成项目内安装。
3. 首次 COM 调用没有返回，由本次助手中断其 PowerShell 调用；没有全局结束 PowerPoint。
4. 第二次有界 COM 尝试能启动 Office，但子 PowerShell 缺少 Get-FileHash 命令。探测脚本改用 .NET SHA256 后，第三次导出成功。失败记录保留，没有将其隐藏成一次成功。
5. QA schema初稿有JSON括号错误，首轮测试检出；修复后重新验证通过。最终测试输出与错误问题分开记录。
