## 这次改变了什么

三张概念图采用一致的纸张、光学玻璃、深蓝、青绿与暖金语言，分别用于封面、人工审核主题页和章节页。它们有具体主题和用途，事实数字仍放在原生可编辑对象中。透明插图保留真实 alpha，不把整页 PPT 栅格化。

正文改为暖白背景，重点数字与结尾采用深色背景；对比、图表和表格的层级、留白及颜色强调分别设计。图表使用原生条形图、直接数据标签与单独结论注释，仍按同一尺度显示人工40分钟与自动1分钟，不改变数据比例。表格保留全部单元格，流程为四个可编辑箭形对象的真实 PowerPoint 组合。

模板包含 **Editorial Cover、Editorial Light、Editorial Dark、Editorial Section** 四种原生母版布局及可编辑标题/内容占位符。这不是只改扩展名：文件主内容类型确认为 PowerPoint 模板，通过 Office 的 `Untitled` 模板复制机制创建了新的十页演示文稿，图表工作簿、文本、表格和流程节点均核对通过。模板目前包含本套示例页，可以复制样页或插入四种布局；它尚不承诺任意内容都能自动填充。

## 真实 MCP 与 Office 验证

本轮使用官方 MCP Python SDK 2.3.0，在项目独立 `.mcp-venv` 中建立 stdio 服务。项目客户端实际发现并调用工具，服务启动自己的 PowerPoint COM worker。真实调用记录在 `mcp-design-call.json`、`mcp-template-reuse-call.json`，不是模拟返回。

已完成：原生 Office 主题应用、自定义主题色、四种母版布局、图表 ChartStyle=10、箭形流程对象组合、PPTX/POTX 保存，以及从 POTX 创建新演示文稿。模板保存使用 [Microsoft 的原生文件格式枚举](https://learn.microsoft.com/en-us/office/vba/api/powerpoint.ppsaveasfiletype)，模板实例化与各页布局关系也保存了本机证据。

服务源码在 `ppt-workflow/office-mcp/`，只提供功能清单、应用本套编辑设计、从模板创建新文稿三个受限工具，输入输出限定在项目目录。不提供任意 Python 执行工具，不接管已有用户 PowerPoint 会话。该服务已通过**项目本地客户端**验证，但尚未注册为当前 Codex 聊天的持久 MCP 工具；没有修改用户的全局配置。

