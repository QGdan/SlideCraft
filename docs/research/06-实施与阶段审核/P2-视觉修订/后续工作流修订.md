# 按用户视觉反馈修订工作流

此文件补充原实施计划，不覆盖已冻结的研究与旧示例。

1. **资料与叙事**：继续使用来源/事实表，确定受众、场景、核心信息及逐页目的。
2. **艺术指导**：记录参考、色彩、材质、排版和页面节奏。先形成封面、证据页与图形页的完整方向，避免只选择三套配色。
3. **模板与资产计划**：优先用户合法品牌模板；没有模板时建立原生母版布局。列出哪些内容用生成式图像、哪些必须保持原生图表/表格/流程，说明局部栅格化范围。
4. **图像生成**：通过宿主图像工具生成主题一致的具体图像，保存完整提示词、模式、来源与 hash。需要精确锁定型号时验证实际API通路，不仅凭提示词名称推断模型。
5. **原生能力探测**：从连接会话或本地MCP/COM读取能力，实际试用母版、图表、组合/SmartArt、模板新建。失败保留证据并明确替代对象，不能把协议支持等同于功能支持。
6. **构建与验收**：根据 spec 创建可编辑证据层；经原生 Office 制作/修订后再次核对对象、数据与资产。导出新revision并逐页查看真实画面。
7. **局部修订**：修正文案、对齐、图像裁切、图表强调与文字排版。同阶段修复持续执行，改统计口径与品牌要求回到相应审核。
8. **用户视觉审核**：提供成品、模板、全尺寸图和对照图，审核风格、尺度与图形表现；测试通过不代替此步骤。
9. **接入 P3**：将上述输入、资产、模板、MCP调用和审阅证据纳入正式CLI与状态/hash门控。当前MCP原型和视觉样例已经做实测，持久宿主配置、新版Skill和完整操作编排仍在P3范围。
