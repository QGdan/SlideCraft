## 明确的支持边界

- 字体表advance和行高用于启发式估计，不是完整shaping/中文禁则引擎。静态溢出和碰撞先报risk；普通、未分组、未旋转文字可以绑定本机COM边界确认。
- 组内旋转/非均匀缩放文字、WordArt、竖排、多列、图表标签布局和完整表格样式继承仍需视觉/目标软件核查。几何外框与文字排版是不同支持范围。
- Slide层对象递归检查；母版和布局中的静态对象若存在，会显式报告未检查，不把继承物件偷偷当作通过。
- 渐变、图片、半透明和不支持的主题填充返回对比度unknown；不默认套白色。
- 这是OPC和部分语义引用检查，未接入完整Open XML SDK schema验证；报告保留该unknown。
- 本阶段没有事实源核查、完整视觉评审、图表数据编辑回存；对应QA状态仍为unverified，不能直接正式交付。
- COM超时或无清理证据时保留quarantine锁，不全局结束POWERPNT。需要人工核对进程归属后恢复，尚无自动强制恢复命令。
- 集成测试依赖本轮真实PowerPoint证据；在没有这些证据的环境会明确skip，不能把skip计为执行通过。

## 可运行入口

在 `ppt-workflow` 目录执行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe scripts/inspect_deck.py ..\03-示例与验收\demo-zh.pptx --out runs\review-preflight-new
.\.venv\Scripts\python.exe scripts/render_deck.py runs\p0-20261014-001\rebuild\demo-zh.pptx --out runs\review-render-new --timeout 60
```

静态入口退出码：0=整体passed，1=failed，2=unverified；没有事实/视觉证据的正常文件返回2是预期行为。out必须不存在，旧输出目录会被拒绝。渲染入口0仅表示本次图像验证通过；其他状态返回2。

复现三页探针：先用 `scripts/create_real_probe.py` 写到新的路径，再用渲染入口导出，不能覆盖已有证据。`collect_p1_evidence.py`用于本阶段证据收集，不是未来的生产CLI。
