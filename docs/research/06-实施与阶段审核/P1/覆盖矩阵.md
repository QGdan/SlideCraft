# P1 检查覆盖矩阵

| 项目 | 自动支持 | 未支持或限制 | 证据类型 |
|---|---|---|---|
| ZIP/XML | 包完整性、安全解析、声明及引用 | 完整OOXML XSD未执行 | 实际文件＋注入 |
| 图表 | axis/crossAx引用、关系、原生对象识别 | 标签碰撞、图形对比度、数据语义 | XML正负例；历史基线 |
| 对象边界 | Slide层非文字对象、组递归、仿射变换、旋转外框 | 母版/布局静态物件单列unknown；形状外框不等于像素墨迹 | 真实OOXML夹具 |
| 文字模型 | 每run、缺字形、粗斜体、段距、点/比例行距、wrap、fontScale | shaping/禁则、特殊文字效果、复杂继承 | 真实OOXML＋本机字体 |
| 表格 | 独立/合并单元格尺寸及普通文字风险 | 样式/主题完整继承、复杂旋转 | cell正负例 |
| 对比度 | 实色、常见主题色、简单tint/shade/lum、粗体大字 | 图片/渐变/半透明/复杂层叠unknown | 正负例 |
| 碰撞 | 普通文本估计带相交 | 任意图形碰撞不自动裁定；有意包含不能算缺陷 | 正负例＋risk标记 |
| PowerPoint | 串行、现有会话保护、图片完整性、普通文字实际边界 | 超时需核对所有权，组内坐标暂不绑定为确定证据 | 本机10页＋3页导出 |
| LibreOffice | 必需工具、独立profile、两段退出码、缺页/坏图验证 | 本机未安装，没有实际转换 | mock故障注入 |
| 内容/编辑性/视觉 | 原生对象库存、未评估状态保留 | 事实表P2；真实编辑回存和完整交付审核P3–P5 | 当前unverified |

模块输出的passed只限其已执行支持域；整体QA保留unknown并返回unverified。失败、未评估和模拟测试不从统计中删除。
