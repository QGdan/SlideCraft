## 统一规则与实施顺序

整套采用暖白背景、深蓝正文和青绿强调色。封面、正文、数字页与结尾都保留同一背景和标题体系。图片收进固定内容区，避免整页照片、深色数字页与浅色正文交替形成不同风格。

| 项目 | 冻结值 |
|---|---|
| 画布 | 16:9，13.333333 × 7.5 英寸 |
| 背景 / 正文 / 强调 | F5F3ED / 162E3B / 117A7E |
| 字体 | Microsoft YaHei |
| 页标题 | 34pt；位置 x=0.7, y=0.93, w=11.9, h=0.87 |
| 正文 | 以22pt为主，局部说明18–20pt |
| 来源与页码 | 11pt，统一位于 y=7.02 |
| 图片内容区 | x=0.7, y=2.12, w=11.9, h=4.56以内 |

实际顺序为：**设计规范 JSON → 在 PowerPoint 中创建十种布局 POTX → 冻结模板/规范 hash → 构建正式内容 → 应用该 POTX → 渲染与审核**。`template-profile.json`、`template-first-office.json` 和 `content-office.json` 记录了这条链路；测试确认模板文件先于内容 spec 创建，应用时检查 hash，修改模板会使原绑定失效。

十种原生布局分别为封面、结论、指标、对比、图表证据、流程、时间线、表格、章节和结尾。双栏、四阶段及图片布局配置了不同的实际占位区域，未使用的 Office 默认布局已删除。通过真实 MCP→PowerPoint 调用，用最终 POTX 新建文稿成功，保留十页示例占位页与十种原生布局。

## 图片元素怎样编辑

主成品的标题、正文、业务图表、表格与流程均保留原生编辑性。三维概念图中的纸张、玻璃、金属及光影仍是图片，不能把 PNG 当成天然带图层的素材。

本轮另外按“报告＋审核镜头”的含义重建了一个可编辑模块。它包含12个原生子对象，支持取消组合、改单个文字、调整颜色与尺寸；保存重开后验证没有栅格子对象。同时交付结构化 SVG，文本、矩形、椭圆和连接线均是独立节点，没有内嵌 PNG。

这个模块是**语义重建的平面版本**，不声称无损分离了原图，也不声称重现三维材质。生成图可用于展示质感，需要修改结构和文字时可选择原生模块。

## 重建方式

在 `ppt-workflow/` 中执行，所有输出目录必须全新：

```powershell
& .mcp-venv/Scripts/python.exe scripts/office_mcp_client.py unified-template runs/unified-template-new
& .venv/Scripts/python.exe scripts/build_unified.py runs/unified-content-new --template runs/unified-template-new/Unified-Ivory.potx
& .mcp-venv/Scripts/python.exe scripts/office_mcp_client.py enhance runs/unified-office-new runs/unified-content-new
& .venv/Scripts/python.exe scripts/render_deck.py runs/unified-office-new/deck.pptx --out runs/unified-office-new/render
& .venv/Scripts/python.exe scripts/inspect_editorial.py runs/unified-content-new runs/unified-office-new
& .venv/Scripts/python.exe scripts/build_editable_art.py runs/editable-art-new
```

请重点审核整套一致性、图片与正文的配合，以及可编辑重建版本是否满足后续修改需求。确认视觉方向后，再把本轮模板优先流程接入P3正式CLI与Skill。
