# 开源素材库优先接入

1. 固定Tabler提交，小批导入教育、研究、协作、流程、数据、工具等图标；保存MIT、来源、原始SVG哈希与中文标签。
2. 保留旧位图检索默认行为，新增明确的image/icon/all类型与分类筛选、中文同义词扩展及混合图册。
3. 新增asset-prepare：按批准风格生成指定颜色/尺寸的SVG与透明PNG、许可、注册片段和逐页选用记录；无需运行时联网或新增渲染依赖。PNG走已验证图片合同，SVG保留源文件，不声称原生形状可编辑。
4. 制作一张图标配原生流程文字的技术验证页，实际PowerPoint导图检查；该页不是业务模板批准或整套PPT效果证明。
5. 运行兼容及新增测试、更新文档/能力声明/Skill，同步安装Skill，汇总工程与视觉证据。

本轮不部署Iconify远端服务，不批量接入第二图标风格或插画库。技术页只为检验项目能力，原客户PPT与既有审批不改。
