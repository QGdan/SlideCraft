# 第19轮：大纲驱动与任务素材包

本轮按用户确认的生产方式调整项目：需求确认 → 详细大纲审核 → 按页收集/预制任务素材 → 模板与代表页审核 → 按详细大纲逐页制作 → 美化与独立审核。没有重新生产业务PPT或伪造用户阶段批准。

大纲除既有content-plan的问题、主张、证据、推理与限制之外，新增production-brief附件，明确每页实际正文、讲述要点与每个视觉任务的用途、搜索词、构图倾向、来源/事实引用和必需标记。字段与页ID/标题对应可由代码校验，内容深度仍需实际研究及人工审核。

新增material-pack命令，将选定素材复制到任务专用“素材”文件夹，保留图标SVG/许可、图片下载原文件、来源、预览、准备件与逐页使用映射。原生图表/关系图/表格需有可编辑源和图片预览。共享检索缓存与任务生产素材分开；模板确定后在批准前完成图标配色等适配，并重打最终包。

新任务由ppt-intake默认声明production_mode: outline-assets-template。大纲阶段必须有详细brief；模板提交前必须有完整素材包并绑定获批brief；制作时图片须来自对应页的素材包，来源不能被替换，必需图片不能遗漏。模板交接及制作交接跟踪素材文件哈希。旧任务没有production_mode时继续接受旧合同，已有规则哈希审核失效机制照旧，不承诺旧批准在代码规则变更后永久有效。

修复旧制作检查拒绝所有新增图片来源的问题：保留原事实及全部获批来源不变，仅允许追加与已登记图片资产关联的视觉来源。新模式同时核对素材包的具体源记录；不放开任意新来源或更改事实。
