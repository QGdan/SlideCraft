## 实现结果

素材现在能携带明确的角色、主体、媒介、画幅、留白、缩放方式和避开内容。模板Skill维护独立共享风格文件，统一材质、线条、角色色、基调和计划参考；不必为了选模板改写已批准大纲。

新增三个命令，已经注册到各自Skill：

|命令|责任Skill|实际产物|
|---|---|---|
|asset-plan|ppt-template|逐素材检索参数、计划提示词、计划参考和选图问题|
|asset-record|ppt-compose|实际使用方式、提示词、参考快照、来源与选用观察|
|trend-prepare|ppt-compose|绑定对应月份事实的原生趋势注释带|

page-prepare新增image-story：上方场景图，下方两组短说明。证据主导的image-led/image-balanced继续沿用，不机械轮换页面。template-catalog现包含两个带实际内容预览的候选系统，旧蓝图列表保持独立。

material-pack支持独立风格文件快照，复制素材的完整实际记录和参考图片，检查声明的视觉要求是否匹配。asset-place核对带记录素材的页与fit。顺手修复缓存检索先返回而绕过画幅/尺寸筛选的问题，使在线计划和离线复用的筛选一致。

## 完整自动化顺序

1. 大纲Skill完成逐页主张、真实正文、证据和视觉需求，等待内容审核。
2. 模板Skill根据品牌/候选风格保存asset-style.json，用asset-plan准备选材任务；来源不够时回到资料与素材准备，不用无关图补齐。
3. 制作Skill仅执行准备子任务：检索/下载或真实生图，查看结果，再asset-record。计划提示词不当作实际调用；新生成图不作为真实场景证据。
4. 预制原生图表、关系图及实际预览，material-pack封存到任务素材目录。独立风格通过materials-plan.asset_style指向，已批准大纲不变。
5. 用素材包制作真实模板代表页，审核字体、色彩、图文比例和裁切。风格或素材变化时更新相应记录与包，不沿用过期审核。
6. 模板获批后按详细大纲逐页制作。图片用asset-place，图表用chart-prepare/trend-prepare，关系用relationship-prepare；最终仍通过editorial-build输出原生文字、图形与数据图表。
7. 美化Skill打磨跨页一致性，审核Skill查看实际Office/WPS导图、来源、事实与编辑对象，再提交成品给用户。作者与审美批准分别记录。

实际字段、命令和使用范围见[素材风格与图像叙事](../ppt-workflow/docs/素材风格与图像叙事.md)。独立风格和视觉任务示例已放在examples/asset-style.json、asset-visual-direction.json；新增构图输入见layout-image-story.json和trend-annotation.json。

## 样例链路的复现

在项目根目录，用项目虚拟环境执行下列顺序；新任务使用新的run-name。预制样件用于取得原生素材的实际预览，随后封存并从包重建最终样例：

```powershell
python 26-素材风格与常用构图-20261022/build_review_brief.py --run-name asset-style-新任务
```

在ppt-workflow目录调用scripts/render_direct.ps1，输入该任务build/candidate.pptx，输出该任务render。然后回到项目根执行：

```powershell
python 26-素材风格与常用构图-20261022/seal_materials.py --run ppt-workflow/runs/asset-style-新任务
```

最后导出build-packed/candidate.pptx到render-packed查看。目录均要求新建，不覆盖先前任务。此样例依赖已有Commons照片缓存；其他题材应按实际大纲检索，不能机械复用它。
