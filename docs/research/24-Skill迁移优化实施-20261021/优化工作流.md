# PPT Skill 迁移优化工作流

日期：2026-10-21。依据23号调研，保留六阶段、任务素材包、事实账本及Office/WPS接口。按以下三批推进，阶段审核看实际成品；普通小修不追加审批。

2026-10-22进度：第一批已实现。用户“继续”授权按优先级推进，第二批现已实现并同步四个安装Skill入口，审核B三类真实内容代表页已生成。第一、二批均未代替用户记录审美通过；第三批已于用户继续后实现，五个相关安装Skill已同步，四页简报与实际链路见../26-素材风格与常用构图-20261022/第三批实施说明.md；审美审核C待用户意见。第二批说明与结果见../25-布局容量与模板适配-20261022/第二批实施说明.md。

## 第一批：内容关系与原生结构（本次实施）

1. 保存受影响文件副本及来源说明，保留原任务和客户PPT。
2. 纠正editorial出口：不再将未支持的语义图或SmartArt画成一个矩形；新增常用原生形状。
3. 在详细大纲中加入可选的关系模型：节点、边、关系依据、阅读顺序；验证ID、来源、结构与批准主张。
4. 实现步骤产出、层级、同维度对照三种配方。关系先确定，几何由编译器计算；长内容不能被截取或默默缩字。
5. 输出原生文字、形状、真实连接符与分组，建立源对象映射；图形片段可进入现有material-pack的source/preview流程。
6. 将入口分配到现有Skill：大纲负责模型，模板负责配方选用，制作负责准备与编译，审核负责最终效果和编辑对象。
7. 用三页实际表达样例导出PowerPoint预览，检查关系、文字、连线、编辑性及原有图表路径的兼容。只运行受影响的必要检查。

**审核A：** 用户看层级、步骤产出、对照三页，判断关系是否明确、表达是否有用；此处不替用户签署审美通过。完成的原生功能可供现有任务显式调用，后续批次待审核意见继续。

## 第二批：布局容量与模板代表页

1. 将关系、证据类型与文字体量作为配方选择条件，返回选择理由与替代方案；不自动机械轮换页面。
2. 补中文、数字、英文混排的换行与字体测量，保留标点规则；先分配标题、来源区，再分配正文和证据。
3. 对长内容依次调整布局比例、选更合适配方或拆页。用户锁定页数时不擅自丢内容。
4. 模板索引保存短说明、适用内容、实际预览和容量；用真实封面、正文、数据代表页决定模板，而非只看空壳。
5. 接入六阶段：大纲给出候选，模板确定系统，制作应用已实现配方。

**审核B：** 同一材料的长正文、图片、数据代表页；确认内容完整、图文比例和模板适配。

## 第三批：素材风格与常用构图

1. 素材需求增加视觉角色、画幅、主体、留白与风格；复用现有在线检索和任务目录。
2. 模板确定后维护一份统一风格说明，插画与图片提示词继承材质、线条、色彩和参考。
3. 逐素材保存实际提示词、参考、来源和用途，允许局部重做；正文、数据图表继续原生。
4. 依真实需求补证据主导、趋势注释、图片叙事等配方，维护真实内容预览。
5. 用一份题材相关的短简报检验整个项目能力，整理项目入口和Skill参考；旧样稿保留。

**审核C：** 整套内容与素材是否协调、构图是否服务主张、文件是否便于二次修改。

## 迁移方式

本次优先自主实现机制：参考presentation-skill的语义布局和容量分配、PPT Master的关系与原生对象分离、MiniMax generator的模块输入输出。不复制许可不明或冲突文件，不安装外部Skill替代本项目。具体版本和源码阅读证据见23号调研。

## 验证与交付

每批保存实现清单、必要检查结果、原生PPT与真实导图。自动检查通过不等于用户视觉审核通过。当前开发样例说明项目功能，不把它们当作真实客户证据或新事实来源。
