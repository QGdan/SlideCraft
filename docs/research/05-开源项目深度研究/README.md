研究读取一手源码、官方文档、论文和文件级许可证；没有安装或运行候选开源项目，也没有重新渲染示例。已有示例检查和新增合成探针已运行。没有项目间实测质量/速度排名。

复现本地核查，在项目根目录运行：

```powershell
python .\05-开源项目深度研究\local_audit.py
```

结果写入本目录。`detected: false` 表示现有检查器漏报；脚本 exit 0 表示实验完成，不能当作缺陷已修复。`undeclared_axis_validator_probe.zip` 是检查器单元输入，故意不构成完整 PPTX，请勿把它当作可打开的演示文稿。

主方案优先于各专题的独立建议。主方案选择初次构建后最多两轮内容修复；未来 CLI、结构化合同、质量门和试点均为拟实施内容。
