## 已落地

1. 新增frame-catalog（模板Skill）和frame-prepare（制作Skill），三类实际原生模板及真实预览可查询。
2. 页面角色、title/body_blocks与标签由大纲提供，主题样式与几何留在模板/制作层；不让模板编写器新增业务行动。
3. 原生片段保存原文与正文对象映射，进入素材包时和最终入页时分别保持页ID、文字、来源及对象一致。
4. 封面采用可编辑文档叠层，章节以大号章节号与留白形成停顿，结尾按行动项对齐；和既有内容页组成连续六页。
5. 大纲、模板、制作、总控四个安装Skill更新，旧任务继续兼容。

## 如何调用

在ppt-workflow目录的项目虚拟环境：

```powershell
python -m ppt_workflow frame-catalog
python -m ppt_workflow template-catalog
python -m ppt_workflow brief-compose --input examples/brief-composition-complete.json --out runs/新任务/composed --node D:/node/node.exe
```

最后一条示例引用本轮已准备的素材包，可重现整套。新题材先写自己的详细大纲、素材与设计系统，勿把样例文字或合成数值当作真实内容。输出目录保持新建。

字段和阶段分工见[封面章节与行动结尾](../ppt-workflow/docs/封面章节与行动结尾.md)。需要重新预制时用prepare_complete_example.py换新的run-name，然后依次导出native-build、material-pack、brief-compose和最终render；旧任务不覆盖。
