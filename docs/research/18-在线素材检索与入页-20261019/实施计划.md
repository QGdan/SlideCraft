# 在线素材检索与入页实施计划

1. 保持旧离线接口兼容，新增asset-discover（Iconify Tabler / Openverse）在线候选检索、显式关键词扩展、分页、来源许可与失败状态；记录缓存命中及实际集合规模。
2. 新增asset-fetch选择单项、有限大小下载、校验和缓存、矢量源保留及PNG准备，断网复用已准备素材。不将网上搜索结果视为已授权的任意镜像库。
3. 新增asset-place将准备件合并到明确页与区域，沿用contain/cover与焦点，登记来源、许可、对象ID和署名，不改变原文件或自动批准。
4. 单元与全量测试，实际检索汽车/教育等不同主题；生成含真实在线素材的技术验证PPT，实际Office导图检查裁切、透明度与文字。失败服务明确未验证。
5. 更新项目阶段Skill、使用文档和能力清单，汇总限制与证据。已安装Skill同步遵循正常审批，不能绕过此前审核失败。
