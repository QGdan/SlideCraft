# 视觉模板深化实施计划

目标：在现有工程可靠性上补齐可复用的视觉表达能力，不把研究或合同数量当作效果提升。

1. 固定版本研究Presenton、pptx-gen、Slidev主题及ImageGen相关Skill；保存原文、许可和来源哈希，区分代码与素材许可，不执行上游代码。
2. 设计可重用的模板蓝图：主题token、真实布局、图片槽、可编辑内容、容量与素材登记；保持旧任务兼容。
3. 实现图片contain/cover排版，消除默认拉伸；提供模板清单和本地蓝图构建命令。先覆盖封面、证据、比较及行动页，不宣称任意模板可用。
4. 用宿主生图生成无文字场景资产并登记来源；文字、图表和过程保留原生，不把整页截图当作可编辑PPT。
5. 更新相关独立Skill及参考，运行针对性测试和全量回归；真实PowerPoint渲染代表页，保存观察与返修证据。
6. 汇总研究迁移、实现边界、可复用调用方式及候选预览。业务审批继续保留，本轮工程样页不登记为用户已批准成品。
