# 源码整理记录

## 删除与保留

从编号历史目录、历史运行及实验目录逐文件删除 6,296 个历史演示文件、讲稿和截图，约 2,009 MiB。另删除 12 个经 ZIP 目录检查确认含这些历史产物的旧交付压缩包，约 477 MiB；并移除两套 editorial-wine 旧参考演示、预览及绑定旧任务的 scene-spec，约 16 MiB。合计释放约 2.4 GiB。删除清单见本目录 JSON 文件。

历史源码、验证文本与研究原始目录保留在本地并由 Git 排除。162 份研究 Markdown 另整理到 `docs/research/`，不附带演示稿和截图。本机现有虚拟环境和 Node 依赖保留，不随源码包分发。

当前功能所需的图标、插画、模板配置、模板预览、基础 POTX 及回归测试夹具保留。测试夹具中的 PPTX 和 ZIP 是检测用样本，属于测试代码资源。`templates/imported/` 中的本机下载模板不进入 Git 或源码包。

## 打包与检查

`tools/package_source.py` 从当前实现、文档和工具生成独立源码包，排除历史目录、运行产物、实验、在线缓存、本机环境及安装报告。压缩包内有逐文件 SHA-256 清单；`dist/package-report.json` 记录大小、文件数及压缩包哈希。

对解压副本使用本机已安装 Python 依赖和 Node 依赖执行检查，没有重新联网安装依赖。Node 依赖通过仅供本次检查的 `NODE_PATH` 指向本机现有目录；团队正常安装应在源码目录执行 `npm ci`。

测试和验证结果见 `source-verification.json`。图表测试的已知失败保留，未修改功能代码，也未删除失败测试。已更新根目录 README、协作指南、当前实现 README 和已知问题文档，提供团队安装、验证和上传入口。

没有创建远程仓库或上传 GitHub。`dist/` 是本地交付目录，不应提交到 Git；应解压后提交源码包里的项目文件。
