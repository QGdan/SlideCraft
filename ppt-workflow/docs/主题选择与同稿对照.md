# 主题选择与同稿对照

由 ppt-template 调用：

```powershell
./.venv/Scripts/python.exe -m ppt_workflow theme-catalog
./.venv/Scripts/python.exe -m ppt_workflow theme-prepare --theme research-light --out runs/新任务/theme
```

第二个主题 ID 是 `showcase-dark`。输出必须是 runs 内不存在的新目录。

两者复用项目既有 academic / technical 色板，并为新原生配方补齐 background、ink、accent、muted、surface、line、secondary 角色。theme-catalog 展示真实四页预览，不按关键词自动判断美观。

| 主题 | 适合场景 | 实际取舍 |
|---|---|---|
| 明亮研究 | 研究资料、课堂、明亮会议室、打印阅读 | 白底青绿，正文和来源保持深色；图片用自然光、暖白或青绿材质 |
| 深色展示 | 可控光线中的短展示、技术方案、大屏 | 深蓝底、浅色文字、薄荷青重点；明亮图片保留独立矩形图幅，先看整页是否突兀 |

制作顺序：

1. 读完整大纲和任务素材，按实际使用环境选择主题，不能只看封面。
2. `theme-prepare` 的 design-system.json 交制作，asset-style.json 作为 asset-plan 的 style、materials-plan 的 asset_style。如已有品牌或用户模板，优先使用原模板，不强行套用这里的主题。
3. 图片仍需实际选取和记录；主题文件没有自带获批图片，也不会自动改原图颜色。模板阶段可在独立风格文件补入真实参考图。
4. 图表、原生关系、封面与结尾均用同一 font/colors 重新预制，进入素材包，再交 brief-compose。不能仅换最终页背景而留下旧配色的图表和原生片段。
5. 展示真实代表页与整套接触表，由用户选方向；主题命令不会写入用户批准。

`layouts` 是已实现的自有配方名称集合，不是导入任意 WPS/Office 模板的适配承诺，也不是 quality-v1 所需 semantic_layouts 的替代。后者仍需根据实际大纲声明容量。当前真实对照包含原生封面、横条图表、图片＋横条图表、行动结尾；其他布局需在本任务用真实文字打样。深色折线/柱图的固定网格线尚未纳入本次对照，不因横条页已查看便宣称所有图型均已验证。

对照样件使用相同文案、事实、来源和同一张报告插画，仅改变原生主题。图表数值来自保留的实际文件像素宽度；它们不代表审美评分或业务成果。图片为已有生成插画，本轮没有生图调用。
