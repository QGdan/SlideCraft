# 从文字说明到可视化页面

本轮沿用米白、深蓝、酒红的视觉方向，改善已有8页样稿的内部构图。示例位于 `templates/editorial-wine-v2/`，属于供用户审核的候选样式，不覆盖已批准模板，也不自动注册为已批准蓝图。

## 按页面任务复用

| 页面任务 | 构图示例 | 复用时要调整什么 |
|---|---|---|
| 封面 | 左侧主张与路径，右侧一个完整的页面表达模型 | 用本任务的核心证据或主题视觉替换模型，不把“结论/证据”字样用于所有封面 |
| 内容拆解 | 左侧编号、结论和解释，右侧清晰的任务单 | 根据实际字段和字数重排，不缩成难读的表单 |
| 图片说明 | 主体图片约占内容区七成，右侧三组短说明 | 先检查原图主体、横纵比与焦点，再确定分栏；说明多时换构图 |
| 模板解释 | 左侧表达原则，右侧两个同比例的版式示范 | 示范要能说明图文与数据的不同需求，正式内容页必须换成真实内容 |
| 数据比较 | 同零基线原生图表，加近距离差值注释 | 保留原始数值、类别顺序、单位与工作簿；强调色只用于重点系列 |
| 操作过程 | 每一步对应一个可辨认的产出物，步骤间用简洁连接线 | 图形须能解释输入与产出，避免只有编号和三个相同方框 |
| 整套审核 | 主张与审核重点，加同一套页面的缩略布局 | 缩略布局只用于说明整体节奏；详细阅读应打开对应原页 |
| 收束 | 大字主张、分隔线和三组短语 | 减少新信息，沿用已讲过的结论与角色色 |

## 实施顺序

1. 大纲阶段写出本页结论、证据、主视觉和真实正文，确定视觉要解释什么。
2. 素材阶段准备对应照片、原始数据或可编辑图形；输入与产出类页面优先尝试原生图形表达。
3. 模板阶段用真实内容试排代表页，检查主视觉、图文比例和字体层次。不能仅凭空白框架选型。
4. 制作、美化阶段参考本目录的 `scene-spec.json` 对象与实际预览，按内容修改几何位置。不要将示例中的步骤、示意数字或太阳能照片照搬到无关主题。
5. 输出后看整套节奏和重点原页；只针对具体问题修订。保留用户审核节点，不为普通排版新增多轮工程检查。

## 本轮具体改动

- 封面从两个散置小框改为一个完整的页面模型，统一右侧焦点。
- 内容页增大任务单和正文，拉开三个信息组。
- 照片页从超宽裁切改为较高的左图右文结构，保留更多屋顶与场景信息。
- 模板页增大版式模型，让标题、主视觉、解释位置清楚可见。
- 数据页沿用原生条形图及68/48/35/20的示意数据，保留20百分点差值和零基线，统一标题边界。
- 制作页从三行文字改成素材包、页面任务和成页的连续图示，主要对象可编辑。
- 审核页用本套页面的原生缩略布局替换通用占位缩略图；数据页缩略条形为同比例原生形状，精确标签与可编辑图表以原第5页为准。
- 结尾增大主张字级并整理下方三组信息，形成收束。

主要文字、图形、连线和第5页图表保留为原生对象；照片为可替换的位图。模板中的缩略页模型不是完整独立幻灯片。新稿与旧稿分别保留，视觉偏好由用户审核。
