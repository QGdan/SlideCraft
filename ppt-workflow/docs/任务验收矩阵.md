# 任务验收范围

P5采用冻结生成器后的示意材料探针。每个支持任务均保存spec、来源、原生成品、PowerPoint渲染与检查记录；功能验收不替代新业务内容和审美的人审。

| 原计划任务 | 本轮材料与边界 | 状态解释 |
|---|---|---|
| 中文答辩 | 10页教学报告自动化方法答辩，保留示意事实与统一模板 | 验证中文标题和正文重排；不是已验证真实论文的完整学术答辩 |
| 中文商务报告 | 10页试点讨论与审批，40/1分钟示意 | 主线模板与原生对象验收 |
| 中英混排技术介绍 | 10页中英混排；84/7/77/12数据未参与图表轴修复回归 | 同模板的留出文字/数据探针，不能据此推断其他模板泛化 |
| 真实学院/品牌模板 | 未收到用户真实模板 | blocked；自有模板不充当此项通过证据 |
| 表格密集资料 | 8页、每页一张三列五行原生表 | 只覆盖该表格系列；多表同页、超长表、自动分页与复杂合并尚未支持 |
| 从现有PPT修改 | 复制自有模板，将40/1更新为36/2，检查34和18同步更新 | 使用P4隔离automizer辅助脚本；不计为主安装包已集成能力 |

统计时保留blocked/未验证，不将缺失任务填为pass。校准资料为P1的成对微型夹具及P2/P4既有样例；P5 mixed-technical在本轮生成器和检查器哈希冻结后执行，不据其结果调整阈值。若执行后需要返修，须标成开发样例并另建留出资料。

完整OOXML校验、交互编辑保存往返、真实品牌兼容、Figma/PPTX往返仍未验证。因此本阶段交付为本地候选工作流，最终正式发布条件尚未全部满足。六类任务的实测成功/失败数以P5审核包的results.json为准，不能只依据这份范围说明宣称验收通过。
