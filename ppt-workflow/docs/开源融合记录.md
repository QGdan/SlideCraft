# 开源方法与能力融合记录

本轮不是更换完整平台。以下已实现项进入生产代码和正式阶段校验，原创适配代码与上游代码复制分开说明。固定提交的许可、原文、字节哈希保存在项目上级10-项目自动化优化实施-20261018/upstreams，不执行下载内容。

| 来源 | 核对版本与方法 | 已融合到本项目 | 边界 |
|---|---|---|---|
| PPTAgent | 833cda553b343be0e486a93b0b57cac962cdd566；源与导出分别审、资源变化使审核失效 | quality-v1内容计划进入生产附件哈希；三维任务审核与真实PPT渲染使用同一绑定；合同/规则变化使旧批准失效 | 原有哈希机制继续使用；未移植HTML转换器或Linux安装栈 |
| PresentBench | e70ff01da962274e1e3cc03f77ec435ad66c5eb6；逐任务细粒度二元问题 | 内容计划生成逐页专属检查问题；审核必须逐一回答，答复有证据，未知项保留 | 未复制其数据集、评测模型或排行榜；不声称本项目获得其分数 |
| PPT Master | b113d23720260c411ee47b2b05a73615f954deeb；封闭设计语言、显式映射与不支持边界 | 集中能力清单、图表语义选择、实际图型分派、禁止静默转横条；语义版式/容量合同 | 未搬入SVG编译器；不承诺任意SVG转原生PPTX |
| pptx-automizer | 既有隔离安装0.9.4及P4实测 | 模板即可复用接口的思路体现在正式semantic_layouts与容量校验 | 实验库仍非默认运行依赖，本轮未重新制作PPT或认证任意会员模板 |
| PptxGenJS | 已锁定4.0.1，本地类型与实现源码 | 直接使用原生bar/column/line能力，增加多类别/多系列、重点色、轴与格式选项 | 仍需后续Office渲染与交互编辑验证；不把编译通过当设计质量通过 |
