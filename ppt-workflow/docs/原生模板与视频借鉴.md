[WPS 官方 MCP](https://open.wps.cn/documents/app-integration-dev/mcp-server/introduction)基于 **WPS 365 开放 API**，官方页面提供企业试用权限申请。这不代表桌面 WPS 商城、母版、动画和所有编辑功能都已暴露。企业路线需用户申请权限并按获批接口接入；当前项目优先验证本地路线，无需先申请企业服务。

## 复用模板和模块

用户先在 PowerPoint/WPS 中选择模板并保存为有权使用的 POTX/PPTX，放入 `templates/imported/`。无需等待 WPS 控制链路完成，就能读取该文件；PowerPoint 仍可处理兼容 PPTX。会员素材、在线模板和下载权限由原服务决定。

新增 MCP 工具 `inspect_template_resources(template_path, output_dir)`，客户端 operation 为 `inspect-template`。输出包括母版、布局、占位符、形状 ID、原生图表/表格标记、主题字体/颜色与资源清单，保留源文件 SHA256。仅读取 OOXML，不打开 Office，不联网获取外部资源，不替代渲染与视觉审核。

按“选择模板→检查资源→确定字体/配色/图表规范→封面+数据页+复杂内容页三张打样→用户审核→对象映射与批量适配→全套渲染→美化与独立审核”执行。当前主构建只验证 unified-v3；外部模板需要制作阶段完成适配验证。POTX 可用现有 instantiate 创建独立副本；PPTX 内容页可在已有隔离填充实验基础上按对象映射适配。
