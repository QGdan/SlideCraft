# 场景模板与分层视觉

视觉专项增量：新增photo_process_side纵向步骤侧图布局，以及asset-search素材筛选。详见[版式与素材设计方法](版式与素材设计方法.md)。

2026-10-19前序新增一个原创模板家族campus-editorial-v1，提供ivory和ink两个变体、四种布局。目的是复用真实构图和图片位，不是多列卡片换背景。当前共有五种：scene_cover、evidence_focus、comparison_focus、photo_process、photo_process_side。

## 使用

在ppt-workflow目录运行：

```powershell
.\.venv\Scripts\python.exe -m ppt_workflow template-catalog
.\.venv\Scripts\python.exe -m ppt_workflow blueprint-build --input examples/campus-blueprint.json --out runs/new-campus-pilot --node D:/node/node.exe
# 深色变体的独立请求
.\.venv\Scripts\python.exe -m ppt_workflow blueprint-build --input examples/campus-blueprint-ink.json --out runs/new-campus-ink --node D:/node/node.exe
```

输出必须全新。成功构建仍返回needs_review/退出码2，不代表错误，也不代表视觉通过。命令归ppt-compose；目录查询归ppt-template。它们不填写或批准六阶段业务状态，不绕过大纲和模板审核。

请求版本blueprint-request/1；先复制示例，再修改来源、事实、文字、图表或项目步骤。每页fields须与选用布局匹配，超出容量会报错，不自动缩字。证据布局最多6类别、2系列；这低于通用编译器12类别、4系列，反映该布局实际空间。未知图型、字段和布局明确拒绝。

## 可复用内容

- templates/campus-editorial-v1/blueprint.json：语义色、字号、图片槽、字段与容量。两个变体共用内容层，封面构图随明暗背景调整。
- 实际输出PPTX包含本次实际使用布局的原生命名layout；设计系统、spec与模板SHA256同时输出。这个真实PPTX可以送模板阶段审核，蓝图JSON本身不是POTX。
- 封面与行动页使用同一背景场景建立主题连续性，数据和辨析页不强行加图；人物与场景仅作示意。
- 所有标题、解释、数值、数据工作簿、对照文字和行动节点保留原生。图片可替换、可调整裁切，内部像素并非原生可编辑元素。

## 图片适配

0.2 image元素新增image_fit:cover/contain，cover配合image_focus:{x:0..1,y:0..1}选择裁切焦点。原图字节不改，PowerPoint保留裁切信息；contain等比居中并允许留白。旧输入未指定fit时继续原行为，新增蓝图主动使用cover。

图片必须登记路径、尺寸、SHA256、来源与许可说明。实际艺术资产在assets/campus-editorial-v1/，同时保存完整提示词、工具来源与示意属性。模型ID未由宿主暴露，不虚构“已调用某个固定版本”。生成使用宿主内置工具，没有增加API key要求。

## 适配边界

新路线已针对本模板代表页执行PowerPoint渲染、原生布局与媒体字节检查。它是独立蓝图编译入口；旧unified-v3的plan/build链不因此扩展成任意品牌模板引擎。真实业务仍须继承批准来源、标题、布局及阶段门禁。

不能把本模板作为用户品牌替代品。不是任意PPTX复制填充、HTML转换、SVG编辑或AI图片自动拆层工具；WPS/Figma往返没有重新认证。Canva当前未连接，不作为必需依赖。模板或代码变化会使旧摘要失效，需重新核对。
