# 视觉优先的制作约定

本项目的主要目标是做出内容扎实、图文适配、整套一致且精美的PPT。常规制作将主要精力用于详细大纲、选材、模板设计与逐页打磨，避免把工作重心变成反复跑工程测试和撰写声明。

制作顺序继续采用：详细大纲 → 按页准备任务素材 → 模板与代表页 → 逐页制作 → 美化和效果审核。阶段审核看具体内容与真实页面，不额外增加研发式审批。

默认只做必要检查：PPT能打开、必需内容与数据正确、图片可用、主要文字与图形没有明显溢出或遮挡、实际目标软件页面可读。修改引擎时检查受影响功能，不因普通排版修改反复跑全项目测试。内部诊断记录留在项目，不把测试计数当作设计质量。

页面文案面向观众。不要每页重复“技术测试、不代表批准”等工程声明。确实使用示意数据时在相关数据页清楚标记；必要的作者、许可与来源保持可见，其余技术说明放到备注或交付说明。

整套一致来自字体、角色色、间距和视觉语言，不等于每页相同背景、相同三栏。设计系统可以为不同布局声明background_color，例如深色封面/数据页、暖白内容页与酒红收尾；未声明时沿用全局背景。

先用真实内容打封面、照片页、数据页等代表页。查看整套接触表调整节奏，再逐页修正文案、换行、裁切与图表主次。优先改善画面，再汇报相关变化；不要用流程描述替代作品。

当前可复用候选视觉系统：templates/editorial-wine-v1。含8页真实PPT、设计系统与接触表，供模板阶段按内容选择；尚不声称任意外部模板都已兼容或用户已批准此风格。
