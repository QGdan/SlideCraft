# 版式与素材选择

数据页先按项目docs/原生图表视觉配方.md运行chart-style-catalog查看三种原生图表＋事实结论区的实际预览。按比较/趋势任务和区域容量选型，再交制作Skill准备；示例中的数值、措辞与日期均为合成数据，不能沿用为用户事实。图表自身可以承担视觉表达，不再强塞装饰图片。

新增插画与可编辑模块按项目docs/插画与原生模块库.md选用：asset-search --type illustration检索2项Open Peeps人物，module-search检索4类原生模块及实际PowerPoint预览。模块与人物分别选用，预览截图不是可编辑输出；先判断本页视觉任务和容量，再把真实候选、示例请求、来源交给制作Skill。

本地库现有5项图片及24项Tabler图标。制作新任务先按项目docs/素材库使用.md运行 `asset-search --type all --query "主题词" --out runs/新检索目录`；指定图标时用--type icon与--style tabler-outline，可加--category。默认不加type仍只查旧图片库，不能因此误报没有图标。查看实际预览后交选用结果给制作Skill的asset-prepare；Iconify在线服务和其他候选仍未接入。

先读绑定项目 `docs/页内排版与素材调用工作流.md`。这里的布局指常规Office/WPS幻灯片内文字、图表、图片的组织，不是改用竖版画布。依据任务画布做内容区域草图，确定阅读顺序、分组、对齐、图文比例与留白；不局限于两种步骤布局。

正式制作前先准备图、表与图形；模板阶段完成代表页选材和风格，制作阶段在批量排版前补齐其余页面。按项目 `docs/开源素材库研究与接入方案.md` 查看已核查候选，不把尚未接入的库说成已可CLI检索。每次任务按页列素材需求，实际执行asset-search并保存results.json，查看原图后记录选择理由；有缺口再检索外部来源、生成或制作原生元素。保存图表与素材准备清单.md及page-visual-plan.md，交接真实预览、来源和选材结果。每页文字搭配有表达作用的视觉内容；原生图表/关系图可满足要求，不需每页都加照片。现有5项位图只是库的起点，图标与可编辑模块按真实能力另行盘点。

先确定每页的阅读顺序和主要视觉证据，再画两种小构图。选择网格、字号层次、图文比例与素材角色；真实代表页比仅写风格形容词更能说明设计。

在绑定项目运行asset-search，可用query、type、category、use、style、min-width筛选人工整理的素材。cover/scene/chapter/spot/process是素材用途标签，不等于模板已兼容。搜索结果是候选，不是美观评分。项目生成图与Tabler图标来源分别登记，真实项目照片须另核对。

选图时读negative_space、recommended_focus、preferred_fit与limitations。背景看留白区，透明主体看边缘和完整性，人物图看视线与动作。将许可声明和来源带入制作请求，不把模拟图中的报表作为真实图表。

photo_process适合横向四步总览；photo_process_side提供纵向步骤和大侧图，文字容量更紧。根据图片原构图和阅读需求选用，不能认定后者总是更好。复杂文字先改布局，保持实际字号和内容覆盖。

完整方法、来源及命令见绑定项目docs/版式与素材设计方法.md。模板人审后才批量适配，保留原品牌和事实。
